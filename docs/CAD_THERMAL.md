# CAD 几何如何真正进入热模型

这是 `0.2.0` 新增的可选路径，依赖原有任务演示基线。旧版合成热节点仍单独运行并标注；打开「CAD 联动设计」后才运行新的控制器/电机分节点模型。所有计算只用于研究教学。

## 最短复现

```bash
python -m unittest discover -s tests -v
python scripts/generate_cad_evidence.py
python -m aerolab run --scenario cooling_fault --cad-preset dense --output output/dense-mission.json
python -m aerolab serve
```

网页打开「CAD 联动设计」，修改长度、宽度、鳍片数、高度、厚度、底板厚度，计算并与来源基准比较。预览、体积、流道、热模型和 STEP 都使用同一个规范化几何参数对象和 SHA-256。硬件选定后运行完整任务，不允许飞行中改质量。

三组预生成参数都有真正的 BRep 实体、STEP 回读和封闭 STL 检查。无需 CAD 内核也可计算任意合法几何并导出三组精确预设 STEP；其他参数的 STEP 导出需要可选 CadQuery。未执行 BRep 验证的自定义参数明确标为解析估计，不因为安装了内核便称已验证。安装与实体再生成见 [CAD.md](CAD.md)。

## 来源事实、假设、结果分开

- 来源事实：[NASA/TM-20230011420](https://ntrs.nasa.gov/citations/20230011420)，Table 2，正文第 13 页：旧版 X-57 散热器，长 388.60 mm、宽 179.50 mm、43 片、鳍片高 41 mm、底板 6 mm、平均鳍厚 1.11 mm、平均间距 3.14 mm。它不是最终 Mod II，也不是获得原始 CAD
- 几何假设：平底板、等厚直鳍、无圆角/孔/真实底面轮廓。间距用 `(W−N·t)/(N−1)` 闭合总宽，不把舍入的 3.14 mm 强行当精确值
- 材料假设：铝密度 2700 kg/m³，导热率 167 W/(m·K)，比热 900 J/(kg·K)。未核实具体合金
- 空气假设：定物性，密度 1.05 kg/m³、动力黏度 2.05×10⁻⁵ Pa·s、导热率 0.029 W/(m·K)、比热 1007 J/(kg·K)。没有高度或温度依赖物性求解
- 几何结果：体积 1,178,985.198 mm³，单件质量 3.183260 kg，内流道受热面积 1.389544 m²，流通面积 0.00540257 m²
- 流道假设：有理想绝热顶盖、无旁路。导出的实体只有散热器，没有盖板、风道或 CFD 流体域

## 方程与适用性

尺寸从 mm 一次转换为 m。流通面积 `Aflow=(N−1)·gap·H`，闭合矩形通道水力直径 `Dh=2·gap·H/(gap+H)`。水力湿周包括理想顶盖，受热面积不包括顶盖。外侧鳍片表面和顶端不贡献本模型对流面积。

`v=m_dot/(rho·Aflow)`；`Re=rho·v·Dh/mu`；`Pr=cp·mu/k`。

层流区 `Re<2300` 使用完全发展、四壁等温矩形管关联式：

`Nu=7.541(1−2.610a+4.970a²−5.119a³+2.702a⁴−0.548a⁵)`，`a=min(gap,H)/max(gap,H)`。

Darcy 摩擦系数（不是 Fanning）：

`f·Re=96(1−1.3553a+1.9467a²−1.7012a³+0.9564a⁴−0.2537a⁵)`。

湍流区 `Re>=3000` 使用光滑管 Gnielinski：

`f=(0.790 ln Re−1.64)⁻²`

`Nu=(f/8)(Re−1000)Pr / [1+12.7 sqrt(f/8)(Pr^(2/3)−1)]`。

2300–3000 之间连续插值端点，明确是未经验证的过渡区插值。四壁等温关联式用于三面加热、顶盖绝热、鳍片非等温的流道，仅是有边界误差的工程近似。层流热入口长度估计 `0.05 Re Pr Dh`，湍流用 `10 Dh` 提示；不添加入口增强来凑数。选择的湍流范围上限 10⁶，Mach≥0.3 或压降达到参考绝对压力 101325 Pa 的 10% 标为不可压定密度假设失效。界面温度超过 150°C 或无有限强迫流动稳态时标为温度适用性之外。通过这些数值检查也不意味着物理模型已验证。

层流 Darcy 摩擦系数参照 NASA 报告式 (27)。湍流与过渡区参考：[Ansys Enclosed Channel Convection](https://ansyshelp.ansys.com/public/Views/Secured/MotorCAD/v252/en/Motor-CAD_UG/MotorCAD/topics/enclosedchannelconvectioncorrelation.html)、[Shah/London 矩形管多项式的研究文献复述](https://eng-web77-v02.ocio.monash.edu/intranet/proceedings/fedsm_icnmm2010/data/pdfs/trk-2/FEDSM-ICNMM2010-30031.pdf)。NASA 报告讨论发展段误差，并使用另一种定热流边界公式；本实现不声称复现 HeaTSSPy。

鳍片效率只应用一次：`eta=tanh(mH)/(mH)`，`m=sqrt(2h/(kAl·t))`，绝热鳍尖。`UA=h(A_base+eta·A_fins)`。

有限空气热容率 `Cair=m_dot·cp`，`Gconv=Cair·[1−exp(−UA/Cair)]`，因此总热导不会超过空气携热能力。无风时强迫对流热导为零；非零热负荷没有有限稳态，返回空温度而不是 NaN/无穷数。忽略自然对流和辐射。

底板一维导热 `Rb=base/(kAl·L·W)`；接触热阻明确假设 `Rc=0.001 K/W`。

- 基准底板平均温度代理：`Tbase=Tin+Q(1/Gconv+Rb)`
- 热源/界面温度代理：`Tinterface=Tbase+Q·Rc`
- 空气出口温度：`Tout=Tin+Q/(m_dot·cp)`

不是器件结温，不计算局部热点或扩散热阻。

压降 `Δp=[fL/Dh+K]·rho·v²/2`，进出口附加损失 `K=1.5` 为教学假设，非 NASA 压降验证。流体功率 `Pfluid=Δp·m_dot/rho`，假设效率 50% 得到所需电功率。流量是规定边界，不是假装求过风扇工作点。稳态工作台显示所需风机功率；任务级模型把它计入供电账目。

## 诚实的 NASA 对照

报告旧版散热器算例的边界为 1080 W、入口 63°C、0.085 kg/s，CFD 热阻 0.0194 K/W，平均底板约 83.95°C。当前新简化模型基准底板约 85.21°C，热阻约 0.02056 K/W，差约 +6.0%。这是一个未经校准的单点对照，不是充分验证或精度承诺。报告自身两种关联式 0.0138 / 0.0335 K/W 相对 CFD 差 −29% / +73%，说明模型形式误差可很大。

只在来源几何和来源边界同时完全一致时显示百分比；变体不伪造 CFD 真值。没有进行 CFD，没有调参拟合。接触热阻产生的 1.08°C 另列为界面温升，不拿它冒充 NASA 的底板温度。

## 接回任务级模型

原模型电机和控制器合并的 0.93 效率仍保留给旧路径。新路径拆成电机 0.95、控制器 `0.93/0.95≈0.978947`，都是合成假设：

- 电机损耗 `Pshaft(1/0.95−1)`
- 控制器损耗 `Pshaft(1/0.93−1/0.95)`
- 二者之和等于旧总损耗 `Pshaft(1/0.93−1)`，不重复计算损耗

电机保留原 14 kJ/K 热容和原合成散热模型。控制器/散热器为独立集总节点，热容为 CAD 固体质量 × 900 J/(kg·K)，另加 0.6 kg 合成控制器热板热容。节点温度是包含串联底板/接触热阻的集总热源界面代理；没有解析内部温差动态或器件热点。95°C 保护阈值仍为演示假设。

每个控制器规定流量 `0.085·fan_command·phase_airflow·cooling_health` kg/s。实际风量对应的电功率与原电机风机 `1.3·fan³` kW 同时计入母线；若电源不足，二分降低实际命令直到供电可负担，流量与传热也一起降低。未供电则强迫风量归零。电机原有被动合成散热单独保留，不将其解释为几何求解结果。

对两类节点分别计算可承受损耗和推进功率上限，取共同上限。使用定输入时间步内指数解。输出同时保留电机温度、控制器温度及逐通道最大值，保护检查两个节点。电池、母线、传动和热量账目可独立检查。

装机教学质量 = 原有系统质量 + 2×CAD散热器质量 + 2×0.6 kg热板 + 1.0 kg假设风道。原有 10 kg 合成电机散热硬件不被擅自替换。飞行功率的质量惩罚仍是原有合成代理，不是空气动力学计算；可比变体均采用相同定义。

## 已生成的真实取舍

固定 1080 W / 63°C / 0.085 kg/s、同材质：

| 参数化方案 | 单件质量 kg | 底板代理 °C | 压降 Pa | 所需风机电功率 W |
|---|---:|---:|---:|---:|
| 43片来源基准 | 3.183260 | 85.209 | 491.072 | 79.507 |
| 31片 / 32mm高 / 5mm底板 | 2.096992 | 91.074 | 491.661 | 79.602 |
| 57片 / 41mm高 / 6mm底板 | 3.851760 | 81.183 | 875.967 | 141.823 |

较密方案更冷，但更重，规定流量的电功率也显著升高。轻方案更热；同宽却更矮，流通面积变小，因此压降不保证下降。数字和九个固定硬件任务结果由 `scripts/generate_cad_evidence.py` 生成，保存在 `examples/cad_thermal_evidence.json`；实体证据见 `cad/manifest.json`。

# 短舱装配演示与复现

## 打开

```bash
python3 -m unittest discover -s tests -v
python3 -m aerolab serve
```

浏览器打开 `http://127.0.0.1:8765/nacelle`。服务仅监听回环地址。主页的六步讲解、系统任务模型与旧版散热器 CAD 实验仍然独立可用。

浏览器渲染由原生 WebGL 完成，模型计算和预览数据生成只依赖 Python 标准库。默认几何 STEP 使用随仓库发布、带校验和的实体；压缩缓存以每块不超过 250000 字节的片段保存，服务自动校验重组，下载仍是一个完整的 STEP 文件；自定义 STEP 再生成需要可选的 `cadquery==2.7.0`。没有内核时不得把自定义几何标成已独立验证的实体。

## 六步设计讲解

点击页头「六步设计讲解」，在不改动工作台参数的前提下，现场重算公开满负荷、公开压力增量参考、低损耗基线、热天及两个设计候选。每屏只回答一个问题，最后同时查看名义收益、代价、负裕度角点和域外诊断。完整说明见 [NACELLE_STORY.md](NACELLE_STORY.md)。返回工程工作台恢复原来的参数、证据和相机。

## 自由装配探索

1. **完整安装**：先辨认局部机翼、短舱与三叶桨。只讲 Mod II 的局部安装关系，不拿 Mod IV 翼尖构型充当同一对象
2. **去壳**：揭开上、下及尾部外壳，看到前部外转子电机、后部并排倾斜的双 CMC、安装支架与独立上进气口
3. **剖切**：检查电机定子/转子间隙、CMC 的高压翅片与低压背板。说明 CPU/ACDC 板节点与散热器节点不能混为一个温度
4. **爆炸**：展示分开的有名称部件；选中部件后追踪对应几何假设、材料和热节点。几何爆炸只是展示变换，求解仍针对组装状态
5. **做一个取舍**：公开满负荷在当前低阶模型中仍可能超出适用域，此时不把原始温度当预测，改用损耗功率着色。可以主动选择「0.25×损耗 · 低负荷网络演示」检查几何敏感性，再切回公开工况观察验证缺口。这不是 25% 飞机功率，不是温度校准。修改顶部低压进气、翅片或电机旁通后，检查新指纹、质量、分路流量、压降与节点温度；只有证据匹配新输入才导出
6. **讲清可信度**：打开来源及模型边界。箭头为降阶网络示意，有效域内固体颜色为节点平均/代理温度；域外改用明确标注的热源功率，未做 CFD。未标定区间与模型不适用状态必须一起展示，不把好看的色图当实测

## 可复现接口

- `GET /api/nacelle/catalog`：参数、范围、来源、边界目录
- `GET /api/nacelle/geometry`：默认组件三角网格、稳定 ID、几何指纹
- `POST /api/nacelle/geometry`：`{"geometry": {...}}` 生成该组参数的装配预览
- `POST /api/nacelle/evaluate`：`{"geometry": {...}, "boundary": {...}}` 解一个装配网络
- `POST /api/nacelle/compare`：同边界下比较默认重建与候选方案
- `POST /api/nacelle/step`：`{"geometry": {...}}` 下载当前几何的实际命名实体 STEP

字段仅接受有限、受限的数值和白名单属性，不接受任意文件路径、外部求解器命令或远程 URL。未知字段和无效几何应得到 400；被占用的计算返回 429；未安装自定义 STEP 内核时返回明确的 503。

## 实体再生成

```bash
python3 -m pip install cadquery==2.7.0
python3 scripts/generate_nacelle.py --out output/nacelle-regenerated
python3 -m unittest discover -s tests -p test_nacelle_geometry.py -v
```

硬件质量是重建实体体积与显式材料假设的乘积，是质量代理。允许的支架/安装接头包络交叠没有被当成精确可制造焊缝；不能将此值当实物称重。局部机翼仅是安装语境，不是短舱新增质量。孔隙、复材层合、实际电机填充率、未建模线束/附件和制造公差不在验证范围。

## 浏览器验收

```bash
python3 -m pip install playwright==1.62.0
python3 -m playwright install --with-deps chromium
python3 tests/ui_smoke.py
python3 tests/ui_cad_smoke.py
python3 tests/ui_nacelle_smoke.py
```

如使用已安装的 Chromium，可设置 `AEROLAB_CHROMIUM=/path/to/chromium`。在 Linux 安装 CJK 字体可避免截图缺字。CI 保存真实浏览器截图与流程结果，必须针对对应提交检查。

视觉检查应包括：
- 完整状态能读懂机翼与短舱安装关系，没有将多构型拼接
- 去壳与纵向剖切能同时识别电机、左右 CMC、翅片和独立入口
- 爆炸不更改物理求解位置，部件仍可选中并有稳定名称
- 编辑、重复计算、请求被中断、编辑后撤回、视图切换、浏览器前进/后退不复活过时证据
- 390 px 手机布局无横向溢出，主要控件可操作
- JSON 和 STEP 对应当前已验证输入；自定义导出限制如实展示

开发云环境的 Chromium 子进程曾因环境 socket 权限无法启动，平台浏览器也拒绝 localhost。此项是**本地 UI 验证阻断**，不属于 UI 测试通过。需使用本分支 CI 的实际运行、截图及最终检查记录完成验收。

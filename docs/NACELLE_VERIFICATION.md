## 不能混同的两种有效性

数值收敛/守恒验证了所写方程的内部核算；不能证明这些降阶方程足以预测实际 X-57。

- 默认公开峰值损耗工况仍超出本模型的定物性温度筛查域
- 采用公开表 7 压力增量的敏感性工况也尚未重现 NASA 的部件温度分析
- 界面将这些结果标成适用域失败，主温度/裕度结论不作为预测显示，着色切换为明确标注的热源功率；原始诊断值仍保留在 JSON
- 可主动选择 0.25×公开损耗的低负荷教学输入，探索有效筛查域内的几何敏感性。它不是 25% 飞机功率，不是温度校准，亦不证明真实设备安全
- 参考流量、温度来自公开分析而非实测，节点定义并不完全等价；差异作为验证缺口保留

## 浏览器验收方法与版本边界

开发环境的浏览器进程实际启动被 socket 权限限制，平台云浏览器访问 localhost 亦被拒绝；因此**未将本地 UI 标为通过**。

本分支配置了真实 Chromium CI 测试，涵盖原有工作台、CAD 散热器及新装配页。新页覆盖四种装配状态、WebGL 像素非空检查、节点选择、几何与计算指纹、过期/取消/重复请求、导航中断和返回、缓存与自定义 STEP、过期下载抑制、JSON 证据及 390 px 布局，并产出实际截图。只有对应提交的 CI 完成且截图被检查后，才能称交互与像素验收完成；不以科学渲染图替代浏览器截图。
